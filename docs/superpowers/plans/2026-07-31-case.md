## Root 1 truth table (bash 5.2.21-verified; use verbatim as tests)

Patterns come from an UNQUOTED expansion (`p=…; case TXT in $p) …`):

| pattern (`$p`) | text | match? |
|-----|------|--------|
| `\x` | `x` | yes |
| `\*` | `*` | yes |
| `\*` | `ab` | no |
| `\?` | `?` | yes |
| `\a` | `a` | yes |
| `a\*b` | `a*b` | yes |
| `\\` | `\` | yes |
| `*` (unquoted, no backslash) | `ab` | yes (still active) |

KEEP (quoted → literal, unchanged): `x='\x'; case x in "$x") …` → NO match
(pattern is literal `\x`). Same root verified for `[[ x == $x ]]` (match) and
`v=xy; p='\x'; ${v#$p}` → `y`.

### Task 1: Root 1 — backslash from an unquoted expansion is a pattern escape

**Files:**
- Modify: `crates/huck-engine/src/expand.rs` — the unquoted branch of
  `expand_word_with_quote_escape` (~2109; the `else { result.push_str(&text) }`).
- Test: `crates/huck-engine/src/expand/tests.rs` (or the nearest pattern tests).

**Interfaces:**
- `expand_word_with_quote_escape(word, shell, escape: fn(&str)->String)` — used
  by `expand_pattern` (escape = `escape_pattern_literal`, glob) and
  `expand_regex_operand` (escape = `regex::escape`). `escape_pattern_literal`
  brackets `*?[]|()` as `[*]`… .

- [ ] **Step 1: Failing tests.** Add behavior tests that run fragments through
  the built shell (or unit-test `expand_pattern` on a `Word` with an unquoted
  `$p` part) for every truth-table row + the KEEP quoted case + `[[ == ]]` +
  `${x#pat}`. Use a script file run identically by bash and huck to control
  exact bytes (backslashes mangle through `-c`), e.g.:

```sh
m() { case "$2" in $1) echo M;; *) echo n;; esac; }
p='\x'; m "$p" x     # expect M
p='\*'; m "$p" '*'   # expect M
p='\*'; m "$p" ab    # expect n
p='\\'; m "$p" '\'   # expect M
```

- [ ] **Step 2: Run, verify fail.**

- [ ] **Step 3: Implement.** In the UNQUOTED branch, walk `text`: on a backslash,
  take the next char `c` and append `escape(&c.to_string())` (so `\*`→`[*]`,
  `\x`→`x`, `\\`→`escape("\\")`); a trailing lone backslash is dropped (bash).
  A non-escaped char passes through raw (unquoted metachars stay active). Do
  NOT change the quoted branch. Confirm `escape_pattern_literal("\\")` yields a
  form both `glob::Pattern` and `extglob_match` treat as a literal backslash —
  if `glob::Pattern("\\")` mis-parses, emit `[\\]` for a data backslash (add a
  unit case either way). Re-verify EVERY truth-table row vs bash and the
  `[[ == ]]` / `${x#pat}` cases.

- [ ] **Step 4: Run tests + regression check.** `cargo test -p huck-engine --lib`
  green. Hand-run 6+ rows through `huck -c` vs bash. Run the existing pattern
  tests (extglob, dbracket, param-expansion) — they must stay green.

- [ ] **Step 5: Commit.** (`v351: backslash from an unquoted expansion is a pattern escape (#350)`, trailer.)
