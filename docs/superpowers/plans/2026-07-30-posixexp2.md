**Interfaces:** `scan_step_param_operand(sep, end, in_dquote, enclosing_dquote, is_pattern)` — `end` is the operand delimiter (`}` for `${...}`, `]` for `${a[...]}`).

- [ ] **Step 1: Reproduce + failing tests.** Confirm:

```

x=1; echo "${x+\p}"     # both \p               (KEEP — non-delimiter backslash)
x=1; echo "${x+a\$b}"   # both a$b               (KEEP — \$ special-dropped)
```

Add tests (engine-level end-to-end is simplest — run the line, capture stdout). Model on existing param tests.

Determine the correct arm(s): the failing case is a double-quoted `${...}` (`enclosing_dquote=true`) with the `\}` in the operand's DEFAULT (non-inner-dquote) sub-scanner.
